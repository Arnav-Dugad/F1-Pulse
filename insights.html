Optional local AI with Ollama

Download and run the small local companion, then open the assistant on your PC. Choose one of your installed Ollama models. The companion uses only loopback addresses; it does not send your briefing to a cloud model.

  1. Run Ollama with a model already installed.
  2. Download the companion and run python f1-pulse-local.py.
  3. Open the local assistant below. If your browser blocks the link, open http://127.0.0.1:8788 on your PC.
